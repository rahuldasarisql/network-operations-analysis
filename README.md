# Network Operations Data Analysis 🌐

## Project Overview
Analyzed 500+ network incident records to identify trends,
SLA breaches, and resolution patterns across Indian cities.

## Key Insights
- 📍 Hyderabad has highest incidents (3338)
- ⚠️ 20.8% SLA breach rate needs immediate attention
- 🔧 Server devices are most problematic
- 📅 Peak incidents recorded in August 2024
- ⏱️ High severity avg resolution: 12.55 hrs

## Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Google Colab

## Visualizations
- Incidents by Location (Bar Chart)
- SLA Breach Rate (Pie Chart)
- Resolution Time by Severity (Bar Chart)
- Monthly Incidents Trend (Line Chart)
